# u-browse -- SSoT Document Browser Generator

`/u-browse [scope] [--only path] [--open]` 명령으로 `.u-maker/docs/` 하위의 모든 `.md` / `.json` 파일을 **개별 HTML**로 1:1 변환하고, **index.html**에서 sidebar navigation으로 전체 문서를 브라우징할 수 있는 뷰어를 생성한다.

**Primary Agent:** u-agent-orchestrator (engine-doc 사용)

> **u-report와의 차이:** `/u-report`는 Phase별 aggregate 리포트(통계, 차트, 교차 검증)를 생성한다. `/u-browse`는 각 소스 문서를 **있는 그대로** 개별 HTML로 변환하여 원본 문서를 편리하게 열람하는 데 목적이 있다.

---

## Arguments

| Argument | Required | Description |
|----------|----------|-------------|
| `scope` | Optional | 대상 앱 이름. 생략 시 전체 앱 또는 단일 앱 자동 감지 |

## Flags

| Flag | Default | Description |
|------|---------|-------------|
| `--only path` | - | 특정 경로만 변환 (예: `--only hjw/02-design`) |
| `--open` | - | 생성 후 브라우저에서 자동 열기 |
| `--clean` | - | 기존 `_browse/` 삭제 후 재생성 |
| `--flat` | - | 디렉토리 구조 없이 단일 폴더에 HTML 생성 |

**파일 명명 규칙:**
- `.md` → `{name}.html` (마크다운 렌더링)
- `.json` → `{name}.data.html` (JSON 포맷팅 + 구문 강조)
- `_index.json`, `app.config.json` → `_index.data.html`, `app.config.data.html`
- 기존 `.html` 파일 (wireframes 등) → 그대로 복사

## Execution Flow

### Step 1: Resolve Scope & Discover Files

1. `u-maker.config.json` → scope 해석 (앱 목록 확인)
2. `.u-maker/docs/{scope}/` 하위 재귀 탐색
3. 대상 파일 수집:
   - `**/*.md` — 마크다운 문서
   - `**/*.json` — JSON 데이터 파일
   - `**/*.html` — 기존 HTML (wireframes 등) → 복사 대상
4. `--only` 플래그 적용 → 경로 필터링
5. `_browse/{scope}/` 디렉토리 생성 (없으면)

**파일 목록 구조화:**

```
fileTree = {
  "hjw": {
    "01-plan": ["srs.md", "srs.json", "ia.md", "ia.json", "roadmap.md", "roadmap.json"],
    "02-design": ["api.md", "api.json", "erd.md", "erd.json", ...],
    "02-design/wireframes": ["index.html", "SCR-001.html", ...],
    "03-dev": [...],
    "04-check": [...]
  },
  "backend": {...},
  ...
}
```

### Step 2: Convert Markdown → HTML

각 `.md` 파일을 독립 HTML 페이지로 변환한다.

**변환 규칙:**

1. **YAML Frontmatter** → 문서 상단 메타 카드로 렌더링
   ```html
   <div class="doc-meta">
     <span class="badge status-final">Final</span>
     <span class="meta-item">Owner: u-agent-planner</span>
     <span class="meta-item">Version: 2.1</span>
     <span class="meta-item">Updated: 2026-03-25</span>
   </div>
   ```

2. **Markdown → HTML** (GFM 지원):
   - 헤딩 (`#`) → `<h1>`~`<h6>` + 자동 id 앵커
   - 테이블 → `<table>` (zebra striping)
   - 코드 블록 → `<pre><code>` (구문 강조)
   - Mermaid 코드 블록 → 인라인 SVG (Mermaid.js CDN)
   - 체크박스 (`- [ ]`) → checkbox UI
   - 링크 → 같은 scope 내 문서 참조 시 상대 경로 HTML로 변환

3. **문서 간 링크 변환:**
   - `[ERD](../02-design/erd.md)` → `href="../02-design/erd.html"`
   - `[API JSON](api.json)` → `href="api.data.html"`

4. **페이지 래핑:**
   ```html
   <!DOCTYPE html>
   <html lang="{language}">
   <head>
     <meta charset="UTF-8">
     <meta name="viewport" content="width=device-width, initial-scale=1.0">
     <title>{filename} — {scope} | u-maker</title>
     <style>/* 공통 스타일 인라인 */</style>
     <script src="https://cdn.jsdelivr.net/npm/mermaid/dist/mermaid.min.js"></script>
   </head>
   <body class="doc-page">
     <header class="doc-header">
       <nav class="breadcrumb">{scope} / {phase} / {filename}</nav>
       <div class="doc-actions">
         <button onclick="history.back()">← Back</button>
         <a href="index.html" target="_top">☰ Index</a>
       </div>
     </header>
     <main class="doc-content">
       {rendered HTML content}
     </main>
     <footer class="doc-footer">
       {license.type} · © {license.owner} · Generated by u-browse
     </footer>
   </body>
   </html>
   ```

### Step 3: Convert JSON → HTML

각 `.json` 파일을 보기 좋은 HTML 페이지로 변환한다.

**변환 규칙:**

1. **JSON 포맷팅:**
   - Pretty-print (2-space indent)
   - 구문 강조 (key: blue, string: green, number: orange, boolean: purple, null: gray)
   - 접기/펼치기 (collapsible) 기능 — 객체/배열 노드별

2. **스마트 렌더링** (JSON 구조에 따라 추가 뷰):
   - **배열 of 객체** → 테이블 뷰 토글 (JSON 뷰 / Table 뷰 전환)
   - **ERD JSON** → 엔티티 카드 뷰 + Mermaid ER 다이어그램
   - **API JSON** → 엔드포인트 목록 뷰 (method 배지 + path + description)
   - **Screen JSON** → 화면 카드 그리드 뷰

3. **페이지 래핑:** Step 2와 동일한 페이지 쉘 사용 (title에 `.data` 표기)

4. **검색 기능:** JSON 내 텍스트 검색 (`Ctrl+F` 강화 — 키/값 하이라이트)

### Step 4: Generate index.html (Main Viewer)

전체 문서를 탐색하는 메인 뷰어.

**레이아웃:**

```
┌──────────────────────────────────────────────────────────┐
│  {ProjectName} — Document Browser                         │
│  Scope: {scope} | Files: {n} | Generated: {date}         │
├──────────────┬───────────────────────────────────────────┤
│  Sidebar     │  Content (iframe)                         │
│              │                                           │
│  🔍 Search   │  ┌─────────────────────────────────────┐ │
│  ┌─────────┐ │  │                                     │ │
│  │ Filter  │ │  │  선택한 문서의 HTML이                  │ │
│  └─────────┘ │  │  iframe으로 로드됨                    │ │
│              │  │                                     │ │
│  📁 hjw      │  │                                     │ │
│  ├─ 01-plan  │  │                                     │ │
│  │  ├ srs    │  │                                     │ │
│  │  │ 📄 .md │  │                                     │ │
│  │  │ 📊 .json│ │                                     │ │
│  │  ├ ia     │  │                                     │ │
│  │  └ roadmap│  │                                     │ │
│  ├─ 02-design│  │                                     │ │
│  │  ├ api    │  │                                     │ │
│  │  ├ erd    │  │                                     │ │
│  │  ├ screens│  │                                     │ │
│  │  └ ...    │  │                                     │ │
│  ├─ 03-dev   │  │                                     │ │
│  └─ 04-check │  │                                     │ │
│              │  │                                     │ │
│  📁 backend  │  └─────────────────────────────────────┘ │
│  📁 common   │                                           │
│              │                                           │
└──────────────┴───────────────────────────────────────────┘
```

**Sidebar 구성:**

1. **검색 필터:** 파일명/경로 키워드 실시간 필터링
2. **파일 트리:** `.u-maker/docs/` 디렉토리 구조를 그대로 반영
   - 폴더: 접기/펼치기 (기본: 첫 번째 depth만 펼침)
   - `.md` 파일: 📄 아이콘 + 문서명 (확장자 숨김)
   - `.json` 파일: 📊 아이콘 + 문서명.data
   - `.html` 파일 (wireframe): 🖼️ 아이콘 + 화면명
   - 같은 이름의 `.md` + `.json`은 **하나의 그룹**으로 표시:
     ```
     ├ api
     │  📄 Markdown
     │  📊 JSON Data
     ```
3. **Status 배지:** 문서의 frontmatter Status (Draft/Review/Final)
4. **파일 카운트:** 각 폴더 옆 `(n)` 파일 수

**Content Area:**

1. `<iframe>` 으로 선택한 문서 HTML 로드
2. iframe 내 문서 페이지는 독립적으로 작동 (직접 URL 접근 가능)
3. iframe 높이 자동 조절 (문서 내용에 맞춤)
4. 초기 상태: 환영 페이지 (scope 요약 + 파일 통계 + 빠른 시작 가이드)

**URL Hash Navigation:**

- `index.html#hjw/02-design/api.html` → 해당 문서 자동 로드
- 문서 클릭 시 hash 업데이트 → 뒤로 가기/앞으로 가기 지원
- 외부에서 직접 링크 공유 가능

## --only Flag

| Value | 동작 |
|-------|------|
| `--only hjw` | hjw 앱 문서만 변환 |
| `--only hjw/02-design` | hjw의 design 문서만 변환 |

| (생략) | 전체 변환 |

`--only` 사용 시에도 `index.html`은 항상 재생성 (지정 경로만 sidebar에 표시).

## /u-loop 연동

`/u-loop` 실행 시 각 단계 완료 후 해당 범위의 문서 뷰어를 갱신할 수 있다:

```
[design 완료] → /u-browse {scope} --only {scope}/02-design
[전체 완료]   → /u-browse {scope}
```

## Safety Rules

1. **소스 문서 무수정:** `.md` / `.json` / `.html` 파일은 읽기만 수행 (READ-ONLY)
2. **`_browse/` 디렉토리만 쓰기:** 생성 파일은 `.u-maker/_browse/` 하위에만 생성
3. **인라인 리소스:** 외부 의존성 없는 단일 HTML (Mermaid.js CDN만 예외)
4. **민감 정보 제외:** `.env` 값, 하드코딩 시크릿은 변환에 포함하지 않음
5. **기존 파일 덮어쓰기:** 같은 scope의 기존 `_browse/`는 경고 없이 덮어쓰기 (스냅샷 개념)
6. **SVG 인라인 필수:** Mermaid 다이어그램은 외부 이미지 파일이 아닌 인라인 SVG로 렌더링
7. **`language.documents` 반영:** UI 레이블 언어는 config 설정을 따름
8. **원본 구조 보존:** 디렉토리 계층은 소스와 동일하게 유지 (`--flat` 제외)
9. **독립 실행 가능:** 각 개별 HTML은 index.html 없이도 단독으로 열람 가능해야 함
