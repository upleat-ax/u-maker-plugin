# .u-maker/docs: SSoT Document Repository

Managed by the u-maker plugin.

| Directory | Scope | Phase |
|-----------|-------|-------|
| `common/01-plan/` | Common | PLAN |
| `common/02-design/` | Common | DESIGN | SSoT Docs(ERD/RTM/UXGuide) & design files (.pen/figma/stitch) |
| `common/03-dev/` | Common | DO |
| `common/05-act/` | Common | ACT |
| `web/01-plan/` ~ `web/04-check/` | web | PLAN~CHECK |
| `{app}/02-design/` | per-app | DESIGN | SSoT Docs, HTML Wireframes, design files |

`common/05-act/`에는 `5_DailyReport_PM_yyyymmddhhmm.md` 형식의 PM 데일리 리포트를 저장한다.
