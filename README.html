Why u-maker

What This Plugin Solves

u-maker enforces document-driven development (SSoT) to eliminate the most common causes of software project failure.

❌ Requirements and code are out of sync — no traceability
✅ 4-Tier ID (USR→FR→US→FT) traces every requirement to test
❌ Skipping phases degrades quality
✅ Phase Gates require all docs to be Final before advancing
❌ Repetitive fix-test cycles waste time
✅ PDCA Loop automates iterations (max 10, auto-exit criteria)
❌ Tech stack rules violated constantly
✅ Hook-based pre-write guards block violations (10 rules)
❌ Document and code versions diverge
✅ Every doc change generates .md + .json simultaneously
Core Concepts

Skills, Agents & SSoT

Three pillars make u-maker work: specialized Skills, role-based Agents, and a Single Source of Truth document system.

🧩

Skill

A self-contained instruction bundle for Claude, defined in SKILL.md. Invoked via slash commands (/skill-name). Each skill declares its own tools, reference docs, agents, and execution logic inline — no shared monolith needed.

🤖

Agent

An AI persona with a specific role and expertise — PM, architect, developer, QA, etc. Each agent independently produces documents and code in its assigned PDCA phase, mimicking a real software team.

📐

SSoT

Single Source of Truth — all requirements, designs, code, and tests live in one document tree. u-maker generates .md + .json + .html simultaneously to guarantee consistency. No scattered Confluence/Figma/Jira.

Skill Structure (Self-contained Pattern)

SKILL.md (frontmatter) 
---
name: u-skill-srs
description: |
  SRS generation/update (FR+NFR → US → FT)
  Triggers: /u-skill-srs, SRS
model: sonnet
user-invocable: true
argument-hint: "[app]"
allowed-tools:
  - Read, Write, Edit, Glob, Grep, Bash
imports:
  - ${PLUGIN_ROOT}/_refer/ssot-standard.md
  - ${PLUGIN_ROOT}/_refer/post-execution-summary.md
agents:
  - u-maker:u-agent-ra
  - u-maker:u-agent-sa
---
💡
Each skill imports only the _refer/ docs it needs and declares its agents directly. Token cost per command: ~11K (down from ~26K, a 55-60% reduction).

Workflow

PDCA Workflow

Plan → Design → Do → Check → Act cycles repeat automatically, with Phase Gates ensuring quality.

PLAN
→
DESIGN
→
DO
→
CHECK
Gap ≥ 90%?
→
ACT
↩

Phase Gate Details

PhaseAgentsKey ActivitiesGate Condition
PLAN PM, SA, UX Roadmap, SRS (FR→US→FT), IA, Index Roadmap + SRS + IA = Final
DESIGN UX, SA, RA UXGuide, Screen, ScreenFlow, Wireframe, ERD, API, RTM ERD + RTM + UXGuide + API + Screen + ScreenFlow = Final
DO UX, DV-FE, DV-BE Screen implementation, Frontend, Backend, Code Doc, Gap Check bun run build success + Match Rate ≥ 90%
CHECK QA TC design, execution (Vitest+Playwright), defect analysis Critical/Major = 0, all FT implemented, build OK
ACT RA, PM Backlog cleanup, Archive, Retrospective, Daily Report Log + Retro completed
⚡
Inner Gap Loop: After DO phase, if Match Rate < 90%, gap FTs are incrementally re-executed (max maxGapRetries, default 3). Full rewrite is forbidden. History is logged in 3_Code_DV.md.

Exit Criteria

All conditions must be met for the loop to terminate:

#ConditionCheck Method
1Critical/Major defects = 04_Report_QA.md parsing
2All FTs in SRS implemented1_SRS_RA.md status check
3Build successfulbun run build

Inner Gap Loop

Match RateAction
≥ 90%Proceed to CHECK phase
< 90%Extract gap FT list → incremental DO per FT → re-measure (max maxGapRetries)

Help

Troubleshooting

Common issues and their solutions.

Commands not visible after deploy
  1. Run ./deploy_local.sh --check
  2. Restart Claude Code
  3. Verify ~/.claude/plugins/cache/u-maker/ exists
  4. Check ~/.claude/skills/u-maker__* symlinks
Document write blocked

Blocked by PreToolUse or Docs-First guard. Run a document skill first (/u-skill-us-add, /u-skill-fr-add, /u-skill-srs), then proceed with implementation.

Build gate failure 
/u-skill-build                      # Check build logs
/u-agent-dv-fe Fix build errors     # FE fix
/u-agent-dv-be Fix build errors     # BE fix
Multi-app document paths confused

Check .u-maker/u-maker.config.json → techStack.monorepo.structure.apps. Always specify the app argument explicitly: /u-skill-xxx <app>.

Loop runs infinitely

Max iteration limit (default 10) auto-terminates the loop. Adjust pdca.maxIterations in .u-maker/u-maker.config.json.

Gap Loop doesn't converge

Inner Gap Loop force-proceeds after maxGapRetries (default 3). Adjust pdca.gapThreshold (default 90%) and pdca.maxGapRetries in config.
